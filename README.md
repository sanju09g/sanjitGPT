# 🧠 SanjitGPT – AI Chat Assistant

📌 **Project Overview**

SanjitGPT is an intelligent AI chat assistant built using **React**, **Node.js**, and **Express.js**.  
It allows users to interact with an AI model, maintain personalized chat sessions, and experience features like **voice input**, **private chats**, and **theme customization (dark or light)**

---

## 🚀 Features

- 🎙️ **Voice Prompt Support** – Speak instead of typing to interact with the AI.  
- 💬 **Private Chat Mode** – Start personal conversations that aren’t stored in history.  
- 🌗 **Theme Switcher** – Toggle between dark and light themes seamlessly.  
- 🔐 **Authentication System** – Secure login and signup using JWT and cookies.  
- 🧩 **Persistent Chat Threads** – Save and revisit previous chat conversations.  
- 🚪 **Logout Functionality** – End sessions securely with proper token handling.  


---

## 🛠️ Technologies Used

### Frontend
- **React (Vite)**  
- **React Router DOM**  
- **Context API** (for global state management)  
- **SpeechRecognition API** (for voice input)  
- **CSS (custom styles)**  

### Backend
- **Node.js**  
- **Express.js**  
- **MongoDB + Mongoose**  
- **JWT (JSON Web Token)**  
- **Cookie Parser & CORS**
